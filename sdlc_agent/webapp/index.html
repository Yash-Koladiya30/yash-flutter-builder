Built on proven patterns

Yash's five-stage SDLC pipeline, distilled from the Agentic AI curriculum and applied end-to-end on-device.

M

Meta-planner + executor

Meta-planning applied at the stage level. An LLM decides which stages to run for your specific idea. The executor validates prereqs and runs each one.

R

RAG over patterns + memory

Two ChromaDB collections: engineering_patterns for curated engineering knowledge, agent_memory for every past run. Both queried during analysis.

L

Local LLM via Ollama

Runs 100% on your machine. No API keys, no rate limits. Per-stage model selection in config.py.

T

Tool-using ReAct agents

Analysis and Coding stages use ReAct loops with file ops, CLI tools, and RAG retrieval. Every tool follows five core principles.
