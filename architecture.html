Flutter SDLC Agent — Architecture

Local-first agent pipeline powered by Ollama. Five sequential stages share a single state dict.

Shared State Dict — flows through every stage

# state.py
state = {
  'idea': <str> # Stage 0 — read-only
  'analysis': <dict> # Stage 1
  'plan': <list> # Stage 2
  'design': <dict> # Stage 3
  'code': <list> # Stage 4 — file log
  'project_dir': <str> # filesystem handle
  'tests': <dict> # Stage 5
  'status': <str> # 'started' → 'complete'
  'errors': <list> # any stage can append
}

Each stage reads upstream keys and writes exactly one new key. No stage mutates keys written by earlier stages.
